## Indicaciones

### Dificultad: Difícil

Los regex son una herramienta poderosa para buscar y manipular texto. En este ejercicio, practicaremos la creación de expresiones regulares complejas.

Sirven para buscar patrones específicos dentro de cadenas de texto. Por ejemplo, podemos usarlos para validar formatos de correo electrónico, números de teléfono o incluso para extraer información específica de un documento.

Esta semana practicaremos con una base de datos acerca de los leucocitos y neutrófilos (células inmunes presentes en la sangre) aprenderemos a limpiar una base de datos para dejarla excelente.

El reto será pulir la base de modo que puedas manejar datos numéricos después de haberlos procesado.

# 05. Intro to Regex

# English

## Instructions

### Difficulty: Hard

Regular expressions (regex) are a powerful tool for searching and manipulating text. In this exercise, we will practice creating complex regular expressions.

They are used to search for specific patterns within text strings. For example, we can use them to validate email formats, phone numbers, or even to extract specific information from a document.

This week, we will practice with a database about leukocytes and neutrophils (immune cells present in the blood) and learn to clean up a database to make it excellent.

The challenge will be to clean the data so that you can handle numerical data after processing it.

Let's practice!
